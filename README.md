# Dify Agent & Chatbot Portfolio

## 📁项目1：AI陪伴玩偶对话系统｜中科智慧数字技术有限公司（实习）
> AI陪伴玩偶原型对话系统，基于Dify工作流完成全流程对话逻辑编排，用于产品原型演示。

### ✨项目要点
- 使用**Code代码节点**实现Python预处理：时段判断、心理风险等级识别、用户年龄段分组；
- 通过If‑Else分支根据风险等级分流，高危场景触发心理干预提示，输出心理援助热线；
- 集成问题分类器，区分实时资讯查询与普通闲聊，实时类请求走联网搜索链路；
- 多路RAG知识库检索，分别获取场景策略、MBTI人格、年龄段回复策略，通过模板节点组装上下文送入LLM；
- 多套独立Prompt策略，区分高危干预、普通陪伴、联网搜索场景；
- 模块化设计，支持原型需求快速迭代调整。
