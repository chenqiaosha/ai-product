# PRD AI陪伴玩偶对话系统
## 1. 项目背景
本项目为AI陪伴玩偶原型系统，面向硬件玩偶产品，实现玩偶与用户自然对话交互。
我负责Dify平台侧对话工作流开发，完成完整的对话逻辑编排，输出可用于原型演示的工作流。

## 2. 项目目标
1. 用户和玩偶对话，玩偶实现多轮连贯陪伴聊天；
2. 识别用户输入心理风险等级、对话时段、用户画像信息，输出适配用户状态的回复；
3. 针对心理高危输入做安全干预，提供心理援助热线；普通对话做到情绪接纳、温和陪伴；
4. 区分实时资讯类提问，支持联网搜索回答时效类问题；
5. 异常场景有兜底，避免输出乱码、幻觉；
6. 工作流模块化设计，支持需求快速迭代调整。

## 3. 核心功能
1. **用户画像与上下文记忆**：接收用户传入的年龄、性别、MBTI画像参数，对话过程保留上下文。
2. **Python代码预处理节点**：
   - 判断当前时段，输出早间/日间/深夜模式上下文；
   - 关键词识别心理风险等级：red高危、yellow负面情绪、green普通；
   - 根据年龄划分年龄段分组，输出age_group变量。
3. **风险等级条件分支**：根据预处理输出的risk_level分流，高危、负面情绪、普通对话分别进入不同LLM提示词链路。
4. **问题分类器**：区分实时资讯类问题与普通闲聊，实时类问题路由至联网搜索节点。
5. **多知识库RAG检索**：分别拉取场景应对策略、MBTI人格、年龄段回复策略知识库；通过模板转换节点做多份知识库内容拼接，送入大模型。
6. **多套LLM提示词策略**：高危心理救助专用Prompt、普通陪伴Prompt、联网搜索Prompt；内置心理危机干预话术，提供国内心理援助热线。
7. **模块化可配置设计**：将风险识别、知识库检索、提示词模块解耦，方便原型需求改动快速迭代。

## 4. 工作流整体流程
> 用户输入（附带age/gender/MBTI画像参数）
→ Python代码预处理节点（时间、风险等级、年龄段计算）
→ If‑Else风险等级分支路由
  👉 red高危分支：进入心理干预专用LLM
  👉 yellow/green分支：进入问题分类器
    → 问题分类器区分：实时查询 / 普通闲聊
    → 实时问题：走联网搜索LLM链路
    → 普通闲聊：多路知识库检索（场景策略、MBTI、年龄段策略）→模板拼接知识库片段 →普通陪伴LLM生成回复
→ 输出回答给到前端/硬件端。

## 5. 依赖与约束
> ⚠️ 本工作流DSL导入后**无法直接完整运行**
1. 工作流多处依赖项目私有知识库，dataset_ids属于公司内部资源，无法导出公开；
2. 部分模型插件依赖内部模型市场插件；
3. DSL仅复原画布节点、Python预处理代码、prompt提示词、分支逻辑，用于展示设计思路。

## 6. 验收标准
1. 正常闲聊对话，结合用户画像给出贴合人设的简短陪伴回复；
2. 识别高危心理输入，触发安全干预逻辑，输出心理援助热线；
3. 识别实时类问题，调用联网搜索完成回答；
4. 不同年龄段、不同风险等级，正确走对应分支逻辑；
5. 工作流模块可快速修改，满足原型迭代演示交付。

## 7. 遇到问题 & 优化复盘
1. 前期变量传递经常出现丢失问题，查阅官方文档，调整节点输出变量引用方式解决；
2. 原型需求频繁改动，将工作流拆分为预处理、检索、提示词独立模块，减少重复修改工作量；
3. 完善心理风险关键词规则，区分真正危险言论与口语化吐槽，减少误判；
4. 多知识库片段合并容易出现内容冗余，通过模板转换节点做内容裁剪组装，优化LLM输入。
